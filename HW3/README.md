# 個人理財記帳與可視化儀表板

以 Streamlit 打造的個人記帳工具，透過側邊欄新增支出紀錄，並以互動式圖表呈現各類別支出比例與每日支出趨勢。資料以 CSV 檔案本地保存，關閉程式後仍可保留。

## 功能

- **新增記帳**：輸入日期、分類、項目名稱與金額，送出後即寫入資料檔。
- **分類管理**：內建餐飲、交通、娛樂、購物、居住、其他六種分類。
- **即時統計**：顯示總支出金額與總記帳筆數。
- **圓餅圖**：呈現各類別支出金額比例（環圈圖）。
- **長條圖**：呈現每日支出金額趨勢。
- **歷史紀錄**：以表格列出所有紀錄，金額以 `NT$` 格式顯示。
- **清空紀錄**：提供二次確認機制，避免誤刪資料。
- **資料驗證**：項目名稱為空時會提示錯誤；金額欄位自動轉為數值，無法解析者以 0 計。

## 專案結構

```
HW3/
├── app.py             # Streamlit 主程式
├── requirements.txt   # 相依套件
├── expenses.csv       # 記帳資料（首次執行時自動建立）
└── README.md
```

## 環境需求

- Python 3.9 以上
- 相依套件：`streamlit`、`pandas`、`plotly`

## 安裝與執行

1. 安裝套件：

   ```bash
   pip install -r requirements.txt
   ```

2. 啟動應用程式：

   ```bash
   streamlit run app.py
   ```

3. 瀏覽器會開啟 Streamlit 頁面（預設為 `http://localhost:8501`）。

## 資料格式

資料儲存於 `app.py` 同目錄下的 `expenses.csv`，編碼為 `utf-8-sig`，欄位如下：

| 欄位     | 說明                       |
| -------- | -------------------------- |
| 日期     | 支出日期（`YYYY-MM-DD`）   |
| 分類     | 支出分類                   |
| 項目名稱 | 支出項目描述               |
| 金額     | 支出金額（整數，新台幣）   |

首次執行時若檔案不存在，程式會自動建立僅含表頭的空檔案。若欄位缺漏，載入時會自動補齊。

## 使用說明

1. 於左側側邊欄「新增記帳」表單填寫資料，點選「新增紀錄」。
2. 主畫面會即時更新統計數字、圓餅圖與每日支出趨勢圖。
3. 下方「歷史紀錄」可檢視所有紀錄。
4. 若要清除全部資料，點選「清空所有紀錄」，再於確認區塊點選「確認清空」。

## 注意事項

- 資料僅保存在本機 CSV 檔案，不會上傳雲端，亦無多人共用或帳號機制。
- 清空紀錄後無法復原，操作前請自行備份 `expenses.csv`。
